币安Alpha交易助手 Chrome插件 使用说明
========================================

安装步骤：
1. 打开Chrome浏览器，进入 chrome://extensions/
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本插件所在的文件夹（D:\LocalGit\binanceAlpha）

文件说明：
- manifest.json: 插件配置文件
- background.js: 后台服务脚本，处理WebSocket连接和消息分发
- content.js: 内容脚本，注入到页面中执行操作和监听网络请求
- popup.html: 插件弹出窗口界面
- popup.js: 弹出窗口交互脚本
- icon.png: 插件图标

功能说明：
1. WebSocket连接（待完善）
   - 可以连接到指定的WebSocket服务器
   - 接收交易指令并自动执行

2. 自动化交易操作
   - 自动创建/管理交易标签页
   - 检查URL，如果不匹配则关闭旧标签页并创建新标签页
   - 根据买卖方向点击对应的标签（买入/卖出）
   - 自动填写价格和数量
   - 查找并点击提交按钮

3. 网络请求拦截
   - 拦截 https://www.binance.com/bapi/asset/v1/private/alpha-trade/order/place 接口
   - 获取接口返回的数据
   - 将结果发送回WebSocket服务器（如果已连接）

测试方法：
1. 点击插件图标，打开弹出窗口
2. 在"测试功能"区域填写以下信息：
   - 链名称：如 bsc
   - 合约地址：币的合约地址
   - 数量：正数为买入，负数为卖出（如 120.5 或 -50.2）
   - 币种：币种代码（如 GAIX）
   - 价格：交易价格（如 0.0234）
   - UnionId：用于关联请求和响应
3. 点击"测试交易"按钮
4. 打开浏览器控制台（F12），查看执行日志

WebSocket消息格式：

接收消息（订单指令）：
{
  "type": "order",
  "data": {
    "chainName": "bsc",
    "address": "0xaafe1f781bc5e4d240c4b73f6748d76079678fa8",
    "amt": "120.5",  // 正数为买入，负数为卖出
    "symbol": "GAIX",
    "price": "0.0234",
    "unionId": "xxxxxxxx"
  }
}

发送消息（订单结果）：
{
  "type": "orderResult",
  "data": {
    "orderData": {
      // 成功时：币安API返回的完整数据
      // 失败时：{ "code": "错误代码", "message": "错误信息" }
    },
    "unionId": "xxxxxxxx",  // 对应请求的unionId
    "bnResp": 1  // 0=用户构建的错误信息，1=币安系统返回
  }
}

错误代码说明：
- URL_MISMATCH: 页面URL不匹配
- EXECUTION_ERROR: 执行过程中出错（附带详细错误信息）

注意事项：
1. 请确保已登录币安账户
2. 测试时请使用小额交易
3. 插件会在后台运行，不影响正常浏览
4. 查看控制台可以看到详细的执行日志
